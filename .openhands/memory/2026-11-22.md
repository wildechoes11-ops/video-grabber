## ytdlp.online live-stream API (reverse engineered)
- `GET https://ytdlp.online/api/v1/stream?command=<yt-dlp args>&job_id=<uuid>&lang_code=en&source=lp&max_minutes=15&live_stop=1&live_from_now=1` → SSE.
- Requires browser cookies (`cf_clearance` is IP+UA bound; `session`/`_sid` for csrf). Send same UA + `referer: https://ytdlp.online/live-stream-downloader`.
- SSE `data:` lines are HTML-escaped yt-dlp/ffmpeg output; `event: live-stop-ready` then `event: close` at end.
- Final line is an anchor: `href="/download/<token>/<urlencoded filename>.mp4"` (NOT /api/v1/file/...), followed by
  `event: close` + `data: {"has_output": true, "outcome": "success"}`. Quota failure = `{"outcome":"quota_exceeded"}`.
- Finished file serves `video/mp4` with `accept-ranges: bytes` → progressive playback via Range proxy works.
- Anonymous "daily recording limit" is small (hit after ~3 recordings); logged-in token is passed as cookie `token=...`.
- Rate limit header: `x-ratelimit-limit: 5`.

## Dashboard built
- `app.py` (FastAPI) + `index.html` on port 12000: POST /api/start, GET /api/status/{id}, /api/video/{id} (Range proxy), /api/download/{id}, POST /api/stop/{id}, `?job=<id>` deep link.
- Cookies in `.ytdlp_cookie` (gitignored), optional `YTDLP_TOKEN` env raises limits. Jobs persisted in `.jobs.json`.

## Proxy integration (quota workaround)
- `GET https://proxys-o6v0.onrender.com/proxy/details` → JSON: `proxy_ip`, `proxy_port`, `proxy_user`, `proxy_pass`,
  `country`, `expires` ("YYYY-MM-DD HH:MM:SS"). Rotating residential proxy, ~20-25 min lifetime. Some exit IPs are dead
  (connect timeouts) → always retry with a fresh one.
- Through a proxy the ytdlp.online daily quota is bypassed (quota is per exit IP). cf_clearance from the original IP
  still validated fine through the proxy.
- Finished files: `/api/v1/file/<t>/<name>.mp4` 302-redirects to `/download/<t>/<name>.mp4`, which serves 200/206
  directly WITHOUT a proxy → playback needs no proxy. Match only `href="..."`, never the local `Destination:` path.
- Env: `PROXY_DETAILS_URL` (set to "" to disable), `MAX_ATTEMPTS` rotation count.
